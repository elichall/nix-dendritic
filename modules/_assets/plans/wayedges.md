# WayEdges Implementation

I want to make a one stop system tray/hub that uses the wayedges package framework to add a side pannel that opens with a keybind and by pressing the WIP system custom module in the waybar.

This pannel can have multipe tabs, these tabs can have things like system specs, information, toggles, nobs for volume ect, programs running, agents running, containers active, work sessions (tmux sessions), services active, etc. sky is the limit i can just plug and play with new pannels and modules once the basic config is together. things like cava can be implemented for audio visualization and an ansi art (dynamic that moves) can be made for the default panel that opens.
